# 🤖 Automação de Envio de Mensagens no WhatsApp

## 📱 Automação de mensagens utilizando Selenium

Projeto desenvolvido em **Python** com o objetivo de automatizar o envio de mensagens pelo **WhatsApp Web**, utilizando **Selenium** para controlar o navegador.

A aplicação permite selecionar um arquivo **Excel** contendo os números de telefone e, a partir desses dados, realizar o envio automático das mensagens.

---

# 🎯 Objetivos do Projeto

Durante o desenvolvimento deste projeto foram praticados os seguintes conceitos:

- 🐍 Automação utilizando Python;

- 🌐 Automação Web utilizando Selenium;

- 📊 Leitura e manipulação de arquivos Excel;

- 📱 Automação do WhatsApp Web;

- 🔄 Processamento de uma lista de contatos;

- 🤖 Envio automático de mensagens;

- ⏱️ Controle de execução e intervalos entre mensagens;


---

# ⚙️ Funcionamento

O funcionamento da automação ocorre da seguinte maneira:

1. 📂 O usuário seleciona o arquivo Excel contendo os números;

2. 📊 O sistema realiza a leitura dos dados presentes na planilha;

3. 🌐 O Selenium abre e controla o WhatsApp Web;

4. 🔎 A aplicação processa os números presentes no arquivo;

5. 💬 A mensagem definida é enviada automaticamente para cada número;

6. 🔄 O processo continua até finalizar a lista de contatos.
